# Приёмка установки и изменений

## Обязательные сценарии на целевой машине

| Проверка | Ожидаемый результат |
|---|---|
| Compose / health | PostgreSQL, Core, Tasks healthy; UI доступен |
| Авторизация | Без верного токена API отклоняет запрос, с токеном UI загружает данные |
| Создай задачу Проверка Linux | Одна новая задача, результат инструмента виден в Developer mode |
| Переименуй её в Проверка сервера | Изменяется UUID созданной задачи |
| Поставь ей высокий приоритет | Та же задача, priority high |
| Как называется задача, которую мы переименовали? | LLM учитывает новое название при настроенном OpenRouter |
| Заверши её | Та же задача становится done |
| Обновление страницы / restart Core | История и задача сохраняются |
| Неоднозначное название / ссылка | Уточнение, без изменения случайной задачи |
| Голос: Покажи устройства | Реальная транскрипция, один вызов tool, текст и аудио |
| Пауза после речи / отмена | Автоотправка по настройке; отменённая запись не отправляется |
| Выбор и preview голоса | Настройки на отдельной странице, выбранный готовый голос воспроизводится |
| Agent / workspace | Online Agent, запуск привязки только в разрешённом каталоге |
| Backup / restore | В отдельной установке восстановлены история и задачи |

В Developer mode проверяйте route source, confidence и длительности этапов.
HTTP 200 и фраза «готово» сами по себе не подтверждают действие: проверьте tool result,
UUID и фактическое состояние задачи. Удаляйте только свои приёмочные задачи.
Тесты голосов через mock не заменяют реальное прослушивание и запись с микрофона.

## Автоматические проверки разработчика

Нужны Python 3.12+, uv, Node 22 и установленные frontend dependencies:

```sh
uv sync --extra test
(cd apps/delta-control-center && npm ci)
sh scripts/check.sh
cd apps/delta-control-center
DELTA_UI_URL=http://localhost:8080 npm run test:e2e
```

Browser tests требуют запущенный проект и Chrome; сценарии могут менять тестовые
данные, используйте отдельную тестовую установку. Исторический baseline от
2026-10-17: 203 backend, 6 frontend unit, 30 Chrome; production build успешен.
Это результат конкретного прогона, не гарантия для любого сервера.

Проверка установки моделей с нуля описана в [DEMO_AND_ACCEPTANCE.md](DEMO_AND_ACCEPTANCE.md).
Latency/corpus: [VOICE_LATENCY.md](VOICE_LATENCY.md),
[LOCAL_INTENT_ROUTING.md](LOCAL_INTENT_ROUTING.md), [NEURAL_VOICE.md](NEURAL_VOICE.md).

## Что фиксировать при каждом релизе

Commit, ОС/CPU/GPU/RAM, версии Docker/Compose, выбранные модели, результаты тестов,
реальные latency и известные ограничения. Секреты и персональные данные не записывать.
Изменение API, настроек, поведения или эксплуатации сопровождается обновлением
соответствующей спецификации и ссылкой в [README](../README.md).
